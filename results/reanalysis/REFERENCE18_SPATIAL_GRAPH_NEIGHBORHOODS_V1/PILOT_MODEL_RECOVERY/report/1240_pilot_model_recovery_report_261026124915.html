Reference18 Spatial Graph Neighborhoods — Pilot Model Recovery

Author

Codex

Published

October 26, 2026

Scope

This report documents deterministic recovery of the PN1–PN8 K-means model. Only the original nine-patient Pilot was used. K was fixed at eight and no 21-patient projection, RCTD, NMF, edgeR, GSEA, ligand–receptor, or Marker analysis was run.

Code 
from pathlib import Path
import json
import pandas as pd

working = Path.cwd()
recovery = working.parent if working.name == "report" else working / "results/reanalysis/REFERENCE18_SPATIAL_GRAPH_NEIGHBORHOODS_V1/PILOT_MODEL_RECOVERY"
if not (recovery / "01_MODEL_PROVENANCE.tsv").exists():
    raise RuntimeError(f"Recovery directory not found from {working}")

provenance = pd.read_csv(recovery / "01_MODEL_PROVENANCE.tsv", sep="\t")
parameters = pd.read_csv(recovery / "02_RECOVERED_MODEL_PARAMETERS.tsv", sep="\t")
reproducibility = pd.read_csv(recovery / "03_PILOT_LABEL_REPRODUCIBILITY.tsv", sep="\t")
confusion = pd.read_csv(recovery / "04_PN_CONFUSION_MATRIX.tsv", sep="\t")
metadata = json.loads((recovery / "models/MODEL_METADATA.json").read_text(encoding="utf-8"))
